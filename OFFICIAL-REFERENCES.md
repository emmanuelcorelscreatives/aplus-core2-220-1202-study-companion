# Official references: A+ Core 2

These are links to the original publishers, not redistributed manuals. The companion was prepared offline on November 25, 2026 using previously captured official context; live availability was not rechecked. Use the current page and supported product version when studying. The review explanations are independently authored, not vendor quotations.

## Scope and preparation

- [CompTIA A+ Core 2 V15](https://www.comptia.org/en-us/certifications/a/core-2-v15/) — confirm 220-1202, obtain the current objectives through the official page, and check exam policies. The four study areas are operating systems, security, software troubleshooting and operational procedures.

## Windows decisions and troubleshooting

- [Microsoft: extend a basic volume](https://learn.microsoft.com/en-us/windows-server/storage/disk-management/extend-a-basic-volume) — check layout and file-system prerequisites before changing storage.
- [Microsoft: configure startup applications](https://support.microsoft.com/en-us/windows/configure-startup-applications-in-windows-115a420a-0bff-4a6f-90e0-1934c844e473) — distinguish startup management from removing essential services.
- [Microsoft: BitLocker recovery overview](https://learn.microsoft.com/en-us/windows/security/operating-system-security/data-protection/bitlocker/recovery-overview) — understand recovery-key identification and authorized recovery planning.
- [Microsoft: how User Account Control works](https://learn.microsoft.com/en-us/windows/security/application-security/application-control/user-account-control/how-it-works) — separate sign-in identity, token elevation and application trust.
- [Microsoft: Windows recovery options](https://support.microsoft.com/en-us/windows/recovery-options-in-windows-31ce2444-7de3-818c-d626-e3b5a3024da5) — compare recovery coverage and prerequisites before choosing a disruptive action.
- [Microsoft: System File Checker](https://support.microsoft.com/en-us/windows/using-system-file-checker-in-windows-365e0031-36b1-6031-f804-8fd86e0ef4ca) — use the supported component/system-file repair sequence for an appropriate fault.
- [Microsoft: clean-boot troubleshooting](https://support.microsoft.com/en-us/topic/how-to-perform-a-clean-boot-in-windows-da2f9573-6eec-00ad-2f8a-a97a1807f3dd) — preserve the restoration steps when isolating a startup conflict.

## Observation and safe administration

- [Microsoft: ipconfig](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/ipconfig) — distinguish display commands from configuration-changing options.
- [Microsoft: nslookup](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/nslookup) — inspect DNS queries without treating them as application tests.
- [Microsoft: ping](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/ping) and [tracert](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/tracert) — interpret the limits of ICMP and hop responses.
- [Microsoft: Windows Security](https://support.microsoft.com/en-us/windows/stay-protected-with-windows-security-2ae0363d-0ada-c064-8b56-6a39afb6a963) — follow supported protection guidance within the organization's incident process.
- [Debian project: chmod manual](https://manpages.debian.org/bookworm/coreutils/chmod.1.en.html) — review symbolic and numeric permission semantics; do not use broad permission changes as a default repair.

Read the referenced page for applicability. A link to a command is not authorization to run it, and a reference index is not proof that a particular repair has been tested.
